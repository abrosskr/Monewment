# 👑 Monewment Management Guide (Platform Overlord Edition)

이 문서는 모뉴먼트 플랫폼의 최상위 관리자가 시스템을 효율적으로 제어하고 리소스를 배포하는 방법을 설명합니다.

## 1. 최상위 관리자 (Super Admin) - "The Overlord"
플랫폼 전체를 관장하며 물리적 인프라(Cluster)와 입점 업체(Organization)를 관리합니다.

### 주요 기능:
*   **Cluster 등록:** 새로운 서버 리전(Seoul, Tokyo 등)을 시스템에 연결합니다.
*   **Org 승인 (Bottom-Up):** 외부 팀이나 법인이 입점을 신청(`PENDING`)하면, 이를 승인하고 CPU/RAM/GPU 쿼타를 할당하여 자원을 바인딩합니다.
*   **프로젝트 강제 확장 (Top-Down):** 특정 업체 하위에 새로운 서비스 공간(Folder)을 즉시 생성하여 배포 준비 상태로 만듭니다.

---

## 2. 기업/팀 관리자 (Org Admin) - "The Brand Manager"
할당받은 자원 내에서 자신의 팀과 프로젝트를 운영합니다.

### 주요 기능:
*   **리소스 할당:** 기업 전체 쿼타 내에서 개별 프로젝트가 사용할 자원을 쪼개어 할당합니다.
*   **팀원 초대:** 프로젝트에 참여할 개발자나 디자이너를 초대하고 권한을 부여합니다.

---

## 3. 리소스 할당 전략 (Guardrails)
모든 자원 사용은 **Quota(쿼타)** 시스템에 의해 강제됩니다.

*   **Hard Cap:** 기업이 할당받은 자원을 초과하여 VM이나 컨테이너를 생성하려고 하면 시스템에서 자동으로 차단합니다.
*   **Pricing Control:** 관리자 콘솔에서 vCPU/RAM 당 단가를 실시간으로 변경하여 수익 모델을 조정할 수 있습니다.

---

## 4. 문제 해결 (Troubleshooting)
*   **Empty Space:** 클러스터에 아직 승인된 조직이 없거나, 백엔드 API와의 연결이 끊겼을 때 나타납니다.
*   **Internal Server Error:** 대시보드에서 500 에러가 발생하면 DB 포트 포워딩(`5433`) 상태를 확인하십시오.
