| Role | 정의 | 권한 범위 | 비고 |
| :--- | :--- | :--- | :--- |

| **ProjectMember** | 실무자 (Worker) | 초대받은 프로젝트 내에서 **허용된 기능(Allowed Features)**만 사용 가능 | 일반 팀원 |

## 2. 사용자 시나리오 (User Flow)

### ✅ Phase 1: 진입 및 온보딩 (기반 구축 완료)
1.  **접속 (Landing):** 사용자가 플랫폼(`localhost:3000`)에 접속.
2.  **인증 (Auth Guard):** 로그인/회원가입 프로세스 통과.
3.  **엔진 생성 (Provisioning):**
    * `[+ Create Engine]` 버튼 클릭.
    * 프로젝트명(ID)과 법인명(Org) 입력.
    * 시스템이 물리적 폴더 및 DB 레코드 생성.

### ✅ Phase 2: 서비스 확장 및 팀 관리 (핵심 기능 구현됨)
4.  **통합 설정 진입:** 대시보드 상단 `[⚙️ 통합 설정]` 버튼 클릭.
5.  **서비스 관리 (Service):**
    * `[Service]` 탭에서 설치된 API 기능 확인.
    * 마켓플레이스에서 유료 기능(AI Bot 등) 확인 및 가상 구매.
6.  **팀원 관리 (Team Collaboration):**
    * `[Team]` 탭에서 이메일로 동료 초대.
    * 초대된 동료에게 'Logs', 'MCP Bot' 등 **세부 권한(Feature Key)** 부여.
    * 관리자(Admin)와 일반 멤버(Member) 구분 표시.
7.  **시스템 인텔리전스 (System Intelligence):**
    * `[General]` 탭 하단에서 **실시간 DB 스키마** 및 **API 명세** 자동 수집/시각화 (Collector).
    * `.env` 환경 변수 에디터 제공.

### 🚧 Phase 3: 운영 및 AI 제어 (개발 예정)
8.  **상세 제어 (Control Center):**
    * 대시보드의 `[상세 관리]` 클릭 시 **개별 프로젝트 페이지**로 진입.
    * 프로젝트별 전용 URL (`/projects/[name]`) 라우팅.
9.  **실시간 로그 & AI (Live Ops):**
    * 실제 터미널(`main.log`) 로그를 웹으로 실시간 스트리밍.
    * 에러 발생 시 AI 에이전트가 자동 감지 및 해결책 제안 채팅.

## 3. 기술 스택 (Tech Stack)

| 구분 | 기술셋 | 역할 |
| :--- | :--- | :--- |
| **Frontend** | Next.js 14+ (App Router) | UI/UX, 대시보드, 설정 페이지, 로그인 세션 관리 |
| **Backend** | FastAPI | REST API, Auth(JWT), 파일 시스템 제어, 프로세스 관리 |
| **Database** | SQLite (SQLAlchemy) | 사용자/프로젝트/팀원 정보 저장 (추후 PostgreSQL 마이그레이션 가능) |
| **Module** | Python `multiprocessing` | 개별 프로젝트 엔진 독립 실행 및 제어 |
| **Intel** | `src.collector` | 시스템 자가 진단 및 메타데이터 자동 수집기 |
