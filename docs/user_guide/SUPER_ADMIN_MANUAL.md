Check the **"Pending Approval"** section\n2. Review organization details:\n   - Organization name\n   - Requested tier (Enterprise, Pro, etc.)\n   - Region preference\n3. Click **"PROCEED APPROVAL"** button\n4. Default quotas will be assigned:\n   - CPU: 20 cores\n   - RAM: 64 GB\n   - GPU: 2 units\n5. Organization status changes to ACTIVE\n\n### Viewing Organization Hierarchy\n\n1. Click on an organization card to expand\n2. View assigned quotas (CPU, RAM, GPU)\n3. See all projects under the organization\n\n---\n\n## 📦 Managing Projects\n\n### Deploying a New Project\n\n1. Expand an organization card\n2. Click **"Deploy Project"** button\n3.
