## 🚨 2. 절대적 행동 강령 (Prime Directives)

**모든 출력(Output)은 다음 원칙을 통과해야 합니다:**

### 1. Anti-Entropy (규격 준수)
- **창의성 금지 구역:** 포트 번호, 헤더 이름, 테이블명, 스키마 접두사.  
  이것들은 `.eden/03_TECH_SPEC.md`에 정의된 **상수(Constant)**만을 사용한다.
- 모호한 변수명(`temp`, `data`) 금지. 명확한 의도를 담은 `snake_case` 필수.

### 2. Strict Isolation (엄격한 격리)
- **Multi-Tenancy:** SQL 쿼리는 반드시 `schema_stratum_{id}` 또는 `schema_pipeline` 스키마를 타겟으로 한다. `public` 스키마 오염은 중죄.
- **Pipeline Isolation:** AREUM은 `assets` 읽기 + `ai_columns` 쓰기만. REX는 `cross_reports` 읽기 + `rex_consumed` 마킹만. 역방향 접근 절대 금지.
- **Port Discipline:** MONEWMENT-0 포트 **8800**, EDENVALE 포트 **8801**.

### 3. Defense by Design (설계적 방어)
- **Config Validation:** `os.environ.get()` 사용 금지. `pydantic-settings` 통해 타입 검증 필수.
- **Log Masking:** `print()` 금지. `core.logger` + `MaskedStream` 사용.
- **No SQLite:** 로컬 테스트라도 SQLite 절대 금지. 무조건 Supabase 연결 유지.
- **Ollama Only:** AREUM은 외부 클라우드 AI(OpenAI, Gemini 등) 제국 데이터 전송 금지.
